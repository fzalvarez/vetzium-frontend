# Producto — características de referencia

Características que comunica el producto (texto recibido del usuario el 2026-10-22).
**No son requisitos a implementar tal cual**: sirven para que lo que se construya esté
alineado. Las reglas de negocio concretas se confirman con el usuario antes de codificar.

La columna "En el sistema" dice dónde encaja hoy en el menú y en qué estado está.

## Agenda

| Característica | Qué promete | En el sistema |
|---|---|---|
| Citas web automáticas | Clientes agendan desde web y app; entran solas a la agenda. | Sin módulo "Agenda/Citas". Lo más cercano: Eventos › Calendario (en construcción). Dashboard muestra "Citas de hoy". |
| Recordatorios automáticos | Avisos de vacunas, desparasitaciones y controles pendientes. | Sin vista. Relacionado: WhatsApp, Marketing. |
| Reprogramación y ausencias | Mover citas, registrar inasistencias con motivo, lista de espera. | Sin vista. |
| Turnos y recursos | Veterinarios, consultorios y equipos en una pantalla; evitar cruces. | Sin vista. |
